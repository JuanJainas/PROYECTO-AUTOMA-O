01 · CONTEXTO

Introducción

Este proyecto busca aplicar principios de mecatrónica a la adaptación de un dispensador de agua para convertirlo en una incubadora automática de huevos de pato.

◈

Problema y necesidad

La propuesta parte de la necesidad de construir un prototipo capaz de controlar automáticamente las condiciones de incubación. La solución integra una estructura reutilizada, electrónica de control y elementos de actuación.

⚙

Enfoque mecatrónico

El proyecto combina diseño estructural, sistema eléctrico, electrónica, sensores, actuadores, programación y automatización en un mismo prototipo.

02 · PROPÓSITO

Objetivos

◎

Objetivo general

Desarrollar una incubadora automática de huevos de pato a partir de un dispensador de agua, integrando un sistema de control electrónico para automatizar las condiciones necesarias del proceso.

⌂

Diseñar

Adaptar la estructura disponible y organizar los elementos del prototipo de forma funcional y segura.

⌁

Integrar

Relacionar sensores, actuadores, alimentación y controlador dentro de un sistema electrónico coherente.

⚙

Automatizar

Implementar la lógica de control y programación necesaria para supervisar y actuar sobre las condiciones del sistema.

03 · AUTOMATIZACIÓN

¿Cómo funciona?

La secuencia exacta de sensores, valores de control y actuadores debe completarse con los datos definitivos del prototipo.

Lectura

02

Procesamiento

03

Actuación

Los actuadores responden según la lógica de control definida para el prototipo.

04

Supervisión

El sistema continúa midiendo y corrigiendo las condiciones mientras permanece en funcionamiento.
