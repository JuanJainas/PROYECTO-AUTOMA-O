PROYECTO · MECATRÓNICA 11-07

De un dispensador de agua a una incubadora automática

Esta página reúne el contexto, objetivos y alcance del prototipo sin añadir especificaciones técnicas que todavía no han sido confirmadas.

01 · DESCRIPCIÓN

El proyecto

Concepto

La estructura principal utiliza un dispensador de agua adaptado para funcionar como incubadora. El sistema incorpora un dispositivo de 420 W como parte del sistema de calentamiento/dispensación indicado para el proyecto.

Automatización

La propuesta busca controlar automáticamente las condiciones necesarias para la incubación mediante sensores, actuadores y un sistema de control electrónico.

02 · ALCANCE

Áreas que integra

A

Estructura

Adaptación física del dispensador y distribución de los elementos del prototipo.

B

Electricidad

Alimentación, conexiones y distribución de energía. Los valores definitivos quedan pendientes.

C

Electrónica

Integración del controlador, sensores y actuadores cuando se definan sus modelos.

D

Software

Programación de la lógica de supervisión y actuación automática.
