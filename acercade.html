MODALIDAD DE MECATRÓNICA

SECCIÓN 11-07

Este proyecto presenta el desarrollo de un servidor NAS con Raspberry Pi 3, diseñado para almacenamiento en red, acceso local a archivos y administración eficiente de la información.

🎯 Objetivo del Proyecto

El objetivo principal de este proyecto es implementar un servidor NAS (Network Attached Storage) capaz de centralizar archivos, copias de seguridad y documentos importantes en un solo dispositivo, accesible desde varios equipos conectados a la misma red.

🔗 Funcionamiento

El sistema funciona conectando la Raspberry Pi 3 a una red local mediante Ethernet, permitiendo compartir carpetas y administrar archivos de forma remota. De esta manera, se obtiene una solución práctica, económica y de bajo consumo energético para almacenamiento doméstico o académico.

🛠️ Componentes y Administración

Para su implementación se utilizan una Raspberry Pi 3, almacenamiento externo HDD o SSD, sistema operativo Raspberry Pi OS Lite y configuración por SSH. Esto permite administrar el servidor de forma segura y mantener un control total sobre los datos almacenados.
